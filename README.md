# 2. How Git Changes My Approach

Using Github changes how I approach programming because I can save different versions of my work instead of worrying about losing progress. Before this, I'd usually just edit and save my files, but now I make smaller changes and then test them and commit them separately so I can track my progress and go back if something isnt working

### 3. Additional .gitignore Entry

One thing I would add to my `.gitignore` is `*.log`, which would prevent log files from being tracked. These files can be generated when running or debugging programs and theyre not necessary for submitting my assignments. Ignoring them would help keep my repository organized.
